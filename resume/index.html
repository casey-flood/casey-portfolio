Values

How I work.

Design in the real material

Storybook prototypes built from the same React components we ship, so a prototype is a first draft of production, not a picture of it.

Alignment is a deliverable

A great design nobody agrees on never ships. I align PM, clinical, engineering, and ops as carefully as I design the screen.

Curiosity before opinions

I shadow people doing the work before I draw anything. The best ideas hide in the workarounds.

Measure what matters

Every project starts with how we'll know it worked, and ends by checking.
