Product Design Hub · 2025 – now

I taught it to everyone else, so it’s a team practice, not a personal hack.

Design-in-code only matters if more people can do it. I built the Product Design Hub and the supporting habits to spread it.For product designers and PMs at Dandy

01 · Why

A practice only one person uses doesn’t scale.

I had set up a faster way to design, in code, with Storybook and Cursor. The next step was making sure other designers could use it without needing me.

02 · What I built

The Product Design Hub.

A hub personalized to your role and goal, with design-engineering resources, how-tos, the design system and more.

A Cursor learning hub.

A step-by-step e-learning I made, recorded with Screen Studio, that walks through setting up Cursor with GitHub, pulling the repos, and more.

Onboarding docs and 1:1s.

Docs like the engineering handoff, plus 1:1s to help teammates set up their own automations.

Weekly design jams.

A running record of the UI and UX changes I made to my coded prototypes: a prototype for each sprint, with a breakdown of what changed and which components were used.

Tools I use

What I used to build it.

The hub and the learning path were made with these.

  • CursorThe AI code editor where I build prototypes and the design system.
  • StorybookWhere the design system and my prototypes live, on production code.
  • Screen StudioScreen recordings, like the walkthroughs in the Cursor e-learning.
  • GitHubWhere the code lives, including the branches for my prototypes.
  • TerminalRunning the project locally and pulling down the repos.
