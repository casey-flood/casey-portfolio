Prototyping · 2025 – now

I build clickable prototypes from the real components.

With the design system in place, I could assemble full, interactive flows from real production components that engineers, doctors and dental designers click through.Storybook · Cursor · Claude · Claude Design

01 · Why

A static file can’t show how 3D software feels.

Dandy Design Center is 3D, interactive software, with scans, 3D designs and AutoCAD-style tools. Static Figma frames can’t capture how it behaves.

So people click through it instead.

A clickable prototype lets people feel the tool and give lightweight, useful feedback.

02 · How

First, in Storybook.

I assembled full, interactive flows from the design system’s real components, in Storybook, for engineers and stakeholders to click through.

Then, in Claude Design.

My coworkers ported the Chairside and Portal design systems into Claude Design, so it uses real production components too. That keeps prototyping fast and efficient, even with scans, 3D designs and AutoCAD.

Minutes, not days.

UI design iteration in code dropped from 30–45 minutes to 5–10.

5–10 min per iteration, down from 30–45

03 · The impact

Sprints moved faster.

Milestone 4 of the Design Editor redesign shipped about 29% faster, at about 25% higher quality.

~29% faster, Milestone 4

More iterations, earlier.

With UI design time down, there was room for more rounds before anything was built.

More time for user research.

Prototypes accurate enough to send to doctors and dental designers for feedback, so I could test ideas with the people who would use them.

Better bets, shipped faster.

A clickable prototype turns a hypothesis into something people can react to, so product changes are educated bets, not guesses.

Code-ready, closer to engineering.

Because prototypes use production components, they work as implementation references, and I can push PRs myself. Design and engineering collaborate on the same thing.

More compelling.

Stakeholders could try an idea before it was built.

“Casey’s prototype is much more compelling than presenting a bulleted list.”

Eileen, Dandy design

Try it before it’s built.

Prototypes on production components moved feedback earlier and gave engineering something real, and code-ready, to build from.
